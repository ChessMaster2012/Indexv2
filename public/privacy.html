Local school-use addendum

This section changes with the county/district selected on Index. It is informational and does not represent approval, contracting, or endorsement by the district.

Open local review guidance · Open district website

1. Scope

This policy describes the current Index website and student study features. Index is an independent project and is not a school-district service.

2. Information used

InformationUse
Account email / Google account identifierAuthentication and account management when a user chooses an account.
Optional first and last nameOptional account display name.
County/district selectionStored locally on the device for interface personalization and local policy/review links.
Notes, study sets, progressStored in browser local storage for the current application.
AI Tutor messagesProcessed by the Index server and sent to the configured third-party text-generation provider to produce a response.
Live-game dataTemporary room codes, display names, questions, answers, scores, and related game state are processed while a live game is active.
Technical request dataThe server may receive standard connection information such as IP address; the AI endpoint uses it for short-lived rate limiting.

3. Data minimization

The application does not request school name, grade, student ID, home address, or phone number for personalization. County/district selection is stored locally on the device. Cloud-drive import is not part of the current application.

4. AI processing

AI Tutor messages are sent through the Index server to the configured external text-generation service. The current server implementation uses Pollinations' text endpoint. Students are instructed not to submit sensitive personal information to the tutor.

5. Authentication

Core study features can be used without an account. Email accounts use server-side password hashing. Google sign-in uses Google's OpenID Connect flow and requests basic identity information needed for sign-in.

6. Retention and deletion

Account records are maintained while the account exists and the application provides account deletion. Browser-stored notes, study sets, progress, rewards, and county selection can be removed through browser site-data controls. Live-game state is temporary and held in server memory while rooms are active.

7. Students and school use

Index is designed to minimize student information, but this policy does not claim that Index is already approved under federal law, Maryland law, or the selected district's policy. Formal school or district use should occur only after applicable review, contracting, consent, and security requirements are satisfied.

8. Security

Index uses HTTPS in production, password hashing for email accounts, server-side AI rate limits, and input sanitization for student-facing names and live-game titles. No service can guarantee absolute security.

9. Changes

This policy may be updated as Index changes. The effective date is shown above.

Index is an independent educational project.
